# Vivasolar Colombia

Sitio web corporativo de Vivasolar Colombia S.A.S.

## Sobre el proyecto

Página web informativa y catálogo de productos para la empresa líder en soluciones de energía solar en Colombia.

## Estructura

- `index.html` - Página principal
- `productos/` - Catálogo de productos (paneles solares, bombas)
- `assets/` - CSS, JavaScript e imágenes
- Políticas y documentación legal
